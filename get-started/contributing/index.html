Improving Infinium

Infinium is an open-source, community-driven project. Described below are several ways to support the project.

Support the Network

Run a Node

An easy and effective way to help the Infinium Network is to run a node. Nodes ensure the network keeps running safe and decentralized. A simple fully synchronized node is enough to help the network, but if you want to go out of your way, you could run an open remote node, to allow other people to connect to it.

We have several guides to help you run and configure your node: How to run a node on VPS, How to add Tor and I2P to your node. See all User Guides.

Develop

Infinium is open source and permissionless; contributors are welcome and encouraged. A developer may contribute in numerous way to different projects:

  • CLI wallet and Daemon: The core wallet, mostly written in C++.
  • This website: Built with HTML, CSS y Javascript.

    • This list only includes the tools stewarded by the core team, but the Infinium ecosystem is much more vast. People can contribute to the development of libraries, services, documentation, graphics, etc. The list is virtually infinite.

    Mine

    Mining ensures the safety of the network. Infinium uses ProgPowZ, an ASIC-resistant algorithm developed by Infinium contributors, which aims to remain mineable by common consumer-grade hardware. For more info about mining see the dedicated Mining page.

    Community Crowdfunding System

    Infinium utilizes a community crowdfunding system whereby projects are proposed for development and community-funded. Funding is held in escrow and remunerated to developers once programming milestones are achieved. Anyone may generate new proposals or fund existing ones.

    The developers working on Infinium are mostly indepentent volunteers, but some of them may be funded through CCS proposals. If you wish to support their efforts by donating some INFs, consider contacting them personally or using tipping services.
